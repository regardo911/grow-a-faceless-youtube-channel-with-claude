# Chapter 11: The Weekly Check

[`template-4-weekly-check.txt`](template-4-weekly-check.txt) is the Sunday check, Template 4 in Appendix A. Paste it in your channel folder. It reads `costs.md`, `revenue-model.md` and `prices.md`, so keep all three filled in. Every row ends in a count, and it should take under 15 minutes. If a row comes back empty, that's what you haven't been measuring; mine was plan usage.

When a row flags something, these are the eight fixes. Each prompt names my videos, so swap in yours:

| File | Example | Fixes |
|---|---:|---|
| [`ex85-new-first-frame.txt`](ex85-new-first-frame.txt) | 85 | two videos that open on the same shot |
| [`ex86-different-outcome.txt`](ex86-different-outcome.txt) | 86 | two videos with the same ending |
| [`ex87-generic-look-to-style-sheet.txt`](ex87-generic-look-to-style-sheet.txt) | 87 | the generic AI look (credit: @0xwhrrari) |
| [`ex88-add-narration.txt`](ex88-add-narration.txt) | 88 | words on screen and no voice |
| [`ex89-voice-plan.txt`](ex89-voice-plan.txt) | 89 | one voice at one speed everywhere |
| [`ex90-re-record-one-sentence.txt`](ex90-re-record-one-sentence.txt) | 90 | one flat line (credit: @free_ai_guides, as they wrote it) |
| [`ex91-match-motion-to-words.txt`](ex91-match-motion-to-words.txt) | 91 | a picture that teaches the opposite |
| [`ex92-wrong-fact-one-chunk.txt`](ex92-wrong-fact-one-chunk.txt) | 92 | a wrong fact in a finished long video |

Example 92 has my film's numbers in it: the sentence's start and end (296.83 s to 306.96 s), its length (10.13 s) and the chunk (240 to 360 s). Put in your own from `timing.json` and your chunk list. After any caption edit, read the caption list; on my run the fix deleted the caption next to it.
