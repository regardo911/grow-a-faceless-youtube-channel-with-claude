# Chapter 1: The Channel That Draws Every Frame in Code

Three prompts that show the range: a 3D Short, a stick-figure explainer and the first minute of a documentary. Run these after [Chapter 2's setup](../02-your-channel-stack/README.md). Chapter 1 has nothing to install.

| File | Example | Makes |
|---|---:|---|
| [`ex01-moon-3d-what-if.txt`](ex01-moon-3d-what-if.txt) | 1 | a 12-second vertical 3D "what if" Short |
| [`ex02-stick-figure-tides.txt`](ex02-stick-figure-tides.txt) | 2 | a 12-second stick-figure explainer |
| [`ex03-documentary-cold-open.txt`](ex03-documentary-cold-open.txt) | 3 | the cold open of a 7-minute documentary |

Example 3 voices a `script.txt` the book doesn't print. Write about 130 words on your own topic first and save them as `script.txt` in the folder.

Before you render, `npx -y hyperframes@0.9.64 check` should print no contrast warning. Swap the question and the captions for your own; the rest of each prompt stays.
